Module 3 Cheat Sheet - Introduction to Shell Scripting
========================================================

Bash shebang
------------
#!/bin/bash

Get the path to a command:
which bash

Pipes, filters, and chaining
----------------------------
Chain filter commands:
ls | sort -r

Pipe manual page into head:
man ls | head -20

Extract column from CSV and remove duplicates:
cut -d "," -f1 names.csv | sort | uniq

Shell and environment variables
-------------------------------
List all shell variables:
set

Define variable:
my_planet=Earth

Display variable:
echo $my_planet

Read user input:
read first_name

List environment variables:
env

Export variable:
export my_planet
export my_galaxy='Milky Way'

Metacharacters
--------------
Comment:
# The shell will not respond to this message

Command separator:
echo 'here are some files and folders'; ls

Wildcard *:
ls *.json

Wildcard ?:
ls file_2021-06-??.json

Quoting
-------
Single quotes (literal):
echo 'My home directory: echo $HOME'

Double quotes (expand variables):
echo "My home directory is $HOME"

Escape with backslash:
echo "This dollar sign should render: \$"

I/O Redirection
---------------
Overwrite file:
echo 'Write this text to file x' > x

Append file:
echo 'Add this line to file x' >> x

Redirect stderr:
bad_command 2> error.log

Append stderr:
bad_command 2>> error.log

Input redirection:
tr "[a-z]" "[A-Z]" < a_text_file.txt

Equivalent:
cat a_text_file.txt | tr "[a-z]" "[A-Z]"

Command Substitution
--------------------
THE_PRESENT=$(date)
echo "There is no time like $THE_PRESENT"

Or shorter:
echo "There is no time like $(date)"

Command line arguments:
./My_Bash_Script.sh arg1 arg2 arg3

Batch vs. concurrent modes
--------------------------
Sequential:
start=$(date); ./MyBigScript.sh ; end=$(date)

Parallel:
./ETL_chunk_one.sh & ./ETL_chunk_two.sh

Scheduling jobs with cron
-------------------------
Open editor:
crontab -e

Syntax:
m h dom mon dow command

Append timestamp every Sunday 6:15 pm:
15 18 * * 0 date >> sundays.txt

Run on first minute of first day of month:
1 0 1 * * ./My_Shell_Script.sh

Backup home directory every Monday at 3 am:
0 3 * * 1 tar -cvf my_backup_path/my_archive.tar.gz $HOME/

List cron jobs:
crontab -l

Conditionals
------------
if [[ $# == 2 ]]
then
  echo "number of arguments is equal to 2"
else
  echo "number of arguments is not equal to 2"
fi

AND:
if [ condition1 ] && [ condition2 ]

OR:
if [ condition1 ] || [ condition2 ]

Logical operators
-----------------
==  equal to
!=  not equal to
<   less than
>   greater than
<=  less than or equal to
>=  greater than or equal to

Arithmetic calculations
-----------------------
$(( ))

Operators:
+ - * /

Example:
echo $((3+2))

Negate:
echo $((-1*-2))

Arrays
------
Declare:
my_array=(1 2 "three" "four" 5)

Add items:
my_array+="six"
my_array+=7

Load from file:
my_array=($(echo $(cat column.txt)))

For loops
---------
Loop 1 to 5:
for i in {0..5}; do
  echo "this is iteration number $i"
done

Print array:
for item in ${my_array[@]}; do
  echo $item
done

Indexing loop:
for i in {0..6}; do
  echo ${my_array[$i]}
done
