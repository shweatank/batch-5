Introduction to Advanced Bash Scripting
=========================================

Estimated time needed: 5 minutes

This reading introduces advanced Bash scripting concepts you will use in the final project hands-on lab.

Objectives
----------
After completing this reading, you will be able to create Bash scripts that:

- use conditional statements
- apply logical operators
- perform basic arithmetic
- create and access arrays
- implement for loops

Conditionals
------------
Conditionals allow scripts to run commands only if certain conditions are met.

Syntax:

if [ condition ]
then
    statement_block_1
else
    statement_block_2
fi

Example:

if [[ $# == 2 ]]
then
  echo "number of arguments is equal to 2"
else
  echo "number of arguments is not equal to 2"
fi

String comparison example:

[ $string_var == "Yes" ]

Logical AND / OR:

if [ condition1 ] && [ condition2 ]; then ...
if [ condition1 ] || [ condition2 ]; then ...

Logical Operators
-----------------
==   equal to  
!=   not equal to  
<=   less than or equal to  
-le  alternative for <=  

Example:

a=1
b=2
if [ $a -le $b ]
then
   echo "a is less than or equal to b"
else
   echo "a is not less than or equal to b"
fi

Arithmetic Calculations
-----------------------
Use $(( )) for integer arithmetic:

echo $((3+2))

a=3
b=2
c=$(($a+$b))
echo $c

Bash truncates floating-point results:

echo $((3/2))   # prints 1

Operators:
+ addition  
- subtraction  
* multiplication  
/ division  

Arrays
------
Create arrays:

my_array=(1 2 "three" "four" 5)

Empty array:

declare -a empty_array

Append elements:

my_array+=("six")
my_array+=(7)

Access elements:

echo ${my_array[0]}
echo ${my_array[2]}
echo ${my_array[@]}

For Loops
---------
Iterate over elements:

for item in ${my_array[@]}; do
  echo $item
done

Using indices:

for i in ${!my_array[@]}; do
  echo ${my_array[$i]}
done

Numeric loop:

N=6
for (( i=0; i<=$N; i++ )) ; do
  echo $i
done

Example script:

#!/usr/bin/env bash
my_array=(1 2 3)
count=0
sum=0
for i in ${!my_array[@]}; do
  echo ${my_array[$i]}
  count=$(($count+1))
  sum=$(($sum+${my_array[$i]}))
done
echo $count
echo $sum

Summary
-------
- Conditionals run commands based on true/false tests  
- Logical operators compare integers  
- Arithmetic operations use $(( ))  
- Arrays store multiple values and allow indexing  
- For loops repeat operations based on a sequence
