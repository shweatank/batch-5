🧠 SECTION 1: Advanced C Programming
Problem P1: Function Pointer–Based Plugin System

Goal
Dispatch operations at runtime using function pointers.

Input (in_buf)

Binary layout (12 bytes):

struct {
    uint32_t op;   // 1=ADD, 2=SUB, 3=AND, 4=OR
    int32_t  a;
    int32_t  b;
};

Output (out_buf)
struct {
    int32_t result;
};

Expected Behavior

Must internally use function pointers

No if-else chains for operation logic

Problem P2: Fixed Memory Pool Allocator

Goal
Simulate a memory allocator using a fixed buffer.

Input
struct {
    uint32_t cmd_count;
    struct {
        uint8_t  cmd;   // 1=ALLOC, 2=FREE
        uint32_t arg;   // size or handle
    } cmds[];
};

Output
struct {
    uint32_t resp_count;
    struct {
        int32_t  status;
        uint32_t handle;
    } resp[];
};

Constraints

❌ malloc/free inside allocator

Handles are logical IDs, not real pointers
