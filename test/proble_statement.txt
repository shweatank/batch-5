🧠 SECTION 1: Advanced C Programming (Intermediate)
P1 — Function Pointer Plugin System (Intermediate)

Goal: runtime selectable operations with function pointers.

Simplifications:

Only two operations supported per plugin.

Single test vector.

No plugin loading from files — choose plugin based on an op_mode input field.

Input (in_buf) (12 bytes):

struct {
  uint32_t op;     // 1=op1, 2=op2
  int32_t  a;
  int32_t  b;
};


Output (out_buf) (4 bytes):

int32_t result;


Constraints: Implementation must use a struct of function pointers for dispatch (no giant switch for the core logic).

P2 — Memory Pool Allocator (Intermediate)

Goal: simple fixed-size allocator simulation.

Simplifications:

Pool size small (e.g., 4 KB).

Single allocation size bucket allowed (variable size but allocator may fail if no contiguous free block).

Simple free validation: only free handles previously returned.

Input format:

u32 cmd_count
repeat cmd_count:
  u8 cmd   // 1=ALLOC, 2=FREE
  u32 arg  // ALLOC=size, FREE=handle


Output format:

u32 resp_count
repeat resp_count:
  int32_t status
  u32 handle_or_zero


Notes: Handles are integer indexes. Implementation must not use malloc inside allocator.

P3 — Bitwise Protocol Parser (Intermediate)

Goal: parse 32-bit frame, toggle one flag, verify CRC with a simple XOR.

Simplifications:

CRC = XOR of the other three bytes (simpler check).

Only a single flag toggle operation (action input bitset).

No complex endianness conversions — assume little-endian host.

Input (8 bytes):

uint32_t frame;
uint32_t action; // bit0 => toggle flag bit2


Output (8 bytes):

uint32_t new_frame;
int32_t  status; // 0 ok, -1 CRC fail
