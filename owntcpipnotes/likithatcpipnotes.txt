////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////10)What is DHCP?
Ans)DHCP stands for dynamic host configuration protocoli it is a network protocol that automatically assigns IP addresses and other essential network settings (like subnet mask, default gateway, and DNS servers) to devices, so they can connect and communicate without manual configuration. 
i)It is applicatio layer.
    How DHCP Works (Step-by-Step)

    Discovery: Client broadcasts a request for network configuration.

    Offer: DHCP server responds with an available IP and settings.

    Request: Client accepts the offered configuration.

    Acknowledgment: Server confirms and leases the IP for a set period.
