===========================================================================i===========================================================================================================6)What is fork()?
Ans)fork() is a system call used to create a new process.
-it creates a child process that is an exact copy of the parent process.
After fork() is called,two processes run:
.👨 Parent process
.👶 Child process
Syntax:
              pid_t fork(void);
✅ On Success:
             parent->returns->child pid
             child->returns->0
❌ On Failure:
             Returns->-1
Example:

#include <stdio.h>
#include <unistd.h>

int main() {
    pid_t pid = fork();

    if(pid == 0){
        printf("This is child process\n");
    }else{
        printf("This is parent process\n");
    }
    return 0;
}

=======================================================================================================================================================================================11)CPU schedulers?
Ans)A CPU Scheduler is a component of the operating system that selects which process from the ready queue will get the CPU next.
Types of CPU Scheduling Algorithms:
----------------------------------
i)First Come First Serve (FCFS)
Process that arrives first gets the CPU first.
ii)Shortest Job First (SJF)
Process with the shortest execution time runs first.
iii)Priority Scheduling
Process with highest priority runs first.
iv)Round Robin (RR)
Each process gets a fixed time slice (time quantum).
v)Multilevel Queue Scheduling
