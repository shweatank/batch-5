5)Types of linux device driver?
Ans)
1️⃣ Character Device Drivers (Char Drivers)
Handle devices one character at a time (byte stream).
Used for keyboard, serial ports, mice, etc.
Example: /dev/ttyS0 (serial port)
2️⃣ Block Device Drivers
Handle devices in fixed-size blocks (random access).
Used for disks, USB drives, SSDs
Example: /dev/sda (hard disk)
3️⃣ Network Device Drivers
Control network interfaces like Ethernet cards, Wi-Fi adapters
Handle sending and receiving network packets
Example: e1000 (Intel Ethernet driver)

8)Top half and bottom half
Ans)Top half
   -----------
   i)Top half should be very fast, because during this time other interrupts are blocked.
   ii)Top half runs immediately to handle the interrupt.
   iii)Does only the essential, fast work.
   iv)Usually runs with interrupts disabled to prevent conflicts.
    Bottom half
   -------------
   i)Runs later, after the top half.
   ii)Handles time-consuming work that the top half cannot do.
   iii)Can run with interrupts enabled, allowing other interrupts to be handled.
   Examples: Softirq, Tasklet, Workqueue in Linux.

11)What is Kmalloc()?
Ans)kmalloc() allocates physically contiguous memory in the kernel space.
Faster than vmalloc.
Suitable for small memory allocations.
Memory can be used for DMA (Direct Memory Access).
Example:
                 void *ptr;
                 ptr = kmalloc(1024, GFP_KERNEL);
                 if (!ptr)
                 return -ENOMEM;
here GFP_KERNEEL->get free pages,it allow sleep
=====================================================================================================12)What is Vmalloc()?
Ans)vmalloc() allocates virtually contiguous memory in kernel space.
Slower than kmalloc.
Suitable for large memory allocations.
Memory can't be used  for DMA.
Example:
                    void *ptr;
                    ptr = vmalloc(4096);
                    if (!ptr)
                    return -ENOMEM;
The kernel creates a virtual address range that is continuous.
Each virtual address is mapped to a specific physical page using page tables.
Example:
Virtual Address	Physical Page
0xA000	5000
0xA001	12000
0xA002	3000
0xA003	9000
=====================================================================================================13)What is DMA?
Ans)DMA stands for direct memory access.
It is a hardware feature that allows devices (like disk controllers, network cards, GPUs) to read/write memory directly without using the CPU.
The CPU initiates the transfer but does not copy the data itself, saving CPU cycles.
DMA controller transfers the data directly.
CPU is free to do other work.
✅ Faster and efficient for large transfers.
DMA APIs
dma_alloc_coherent() → allocate DMA-safe memory.

=====================================================================================================16)What is dts?
Ans)DTS stands for device tree source.
it is a text file and human-readable text file.
The name of DTS files should end with “.dts”.
How DTS works:
uart0: serial@101f1000 {
    compatible = "arm,pl011";  // driver matches this device
    reg = <0x101f1000 0x1000>; // physical memory address and size
    interrupts = <29>;          // IRQ number
};
Compile DTS → DTB
DTS is compiled using DTC (Device Tree Compiler) into DTB (Device Tree Blob)
DTB = binary file that Linux kernel can read at boot
Kernel reads DTB at boot
Driver matches device using compatible string.
static const struct of_device_id my_uart_dt_ids[] = {
    { .compatible = "arm,pl011" },
    {},
};
Kernel calls the probe() function of the driver for this device.
Purpose of DTS:
It tells the kernel about all the hardware on the board.
It provides:
Which devices exist
Where they are in memory (reg)
What interrupts they use (interrupts)
Any other configuration like clocks, GPIOs
What happens without DTS?
Kernel has no idea about hardware.
Drivers cannot find devices automatically.
Without DTS: Kernel cannot find or initialize hardware → board may not work.
With DTS: Kernel knows all hardware locations and configurations → can load drivers and use devices properly.
Purpose: Makes embedded Linux portable, maintainable, and reliable.

-Device drivers can create their own entries in /proc so userspace programs can interact with them.

            struct proc_dir_entry *entry;
            entry = proc_create("my_driver_info", 0, NULL, &my_fops);
=====================================================================================================18)What is /sys?
Ans)/sys=sysfs
-/sys is the sysfs filesystem, a virtual filesystem created by the Linux kernel.
-Purpose: to provide a structured, hierarchical view of kernel objects and hardware devices.
-Unlike /proc, which is mostly about processes and system info, /sys is device- and kernel-object oriented.

19)what is ioremap()?
Ans)
-ioremap() is a kernel function that maps physical memory addresses of hardware devices (like memory-mapped I/O registers) into the kernel’s virtual address space.
-Physical memory used by devices cannot be accessed directly by kernel code. ioremap() gives the kernel a virtual pointer to safely access that memory.
Example:
                  void __iomem *reg_base;
                  reg_base = ioremap(0x101f1000, 0x1000);

21)What is copy_to_user() and copy_from_user()?
Ans)For character devices, you often need to transfer data between kernel space and userspace safely.
copy_to_user() → kernel → userspace
copy_from_user() → userspace → kernel
Example:
copy_to_user(buf, kernel_buffer, size);
copy_from_user(kernel_buffer, buf, size);
